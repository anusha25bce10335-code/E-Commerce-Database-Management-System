# Database Overview

## 1. Introduction

An e-commerce database is used to store and manage information related to an online shopping system. It stores details about customers, products, orders, payments, shipments, reviews, suppliers, and shopping carts.

The database helps organize large amounts of data and allows users to easily insert, update, delete, and retrieve information.

---

## 2. Purpose of the Database

The main purposes of the e-commerce database are:

- To store customer information.
- To maintain product and category details.
- To record customer orders.
- To manage payments and shipments.
- To store product reviews.
- To maintain shopping cart information.
- To manage supplier information.
- To maintain relationships between different types of data.

---

## 3. What is a Database?

A database is an organized collection of related data that can be easily accessed, managed, and updated.

For example, an e-commerce database can contain customer, product, and order information in different tables.

---

## 4. What is DBMS?

DBMS stands for **Database Management System**.

A DBMS is software that allows users to create, store, manage, retrieve, and modify data in a database.

Examples of DBMS are:

- MySQL
- Oracle
- PostgreSQL
- Microsoft SQL Server

---

## 5. Advantages of Using a DBMS

### 1. Data Organization
Data is stored in a structured manner using tables and relationships.

### 2. Reduced Data Redundancy
A DBMS helps reduce unnecessary duplication of data.

### 3. Data Security
Access to the database can be controlled using users and permissions.

### 4. Data Integrity
Constraints help ensure that stored data is accurate and consistent.

### 5. Easy Data Retrieval
SQL can be used to quickly retrieve required information.

### 6. Data Sharing
Multiple users and applications can access the database when permitted.

### 7. Backup and Recovery
DBMS provides mechanisms for protecting data and recovering it after failures.

---

## 6. E-Commerce Database Components

The main components of our e-commerce database are:

| Entity | Purpose |
|---|---|
| Customer | Stores customer information |
| Category | Stores product categories |
| Product | Stores product details |
| Supplier | Stores supplier information |
| Order | Stores customer orders |
| Order_Item | Stores products included in an order |
| Payment | Stores payment information |
| Shipment | Stores shipping information |
| Review | Stores customer reviews |
| Cart | Stores shopping cart items |
| Product_Supplier | Connects products with suppliers |

---

## 7. Conclusion

The e-commerce database provides a structured way to manage information related to online shopping. By using a DBMS, customer, product, order, payment, and other information can be stored and managed efficiently while maintaining data consistency and integrity.
